### **Project 3: Network Traffic Analysis & Protocol Validation**

#### **The Goal**
- To analyze network packets in real-time using Wireshark, validating the security difference between encrypted (HTTPS)
   and unencrypted (HTTP) traffic.

#### **Technical Implementations**
- **Tools used:** Wireshark via Kali Linux.
- **Targets:** Network traffic generated by Windows 11 Target Node.
- **Protocol Monitored:** HTTP (TCP Port 80).
